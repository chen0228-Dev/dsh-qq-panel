# 刷抖音采集端

跑在**你自己的电脑**上，不是服务器。

服务器只剩几百兆内存、也没装浏览器；而点赞/收藏/分享是**写操作**，只读接口给不了，
必须有真浏览器带着登录态去点。所以采集在这一端，服务器只负责发配置、收结果。

> 电脑关机 = 今天不刷抖音。**别的功能一律不受影响**——聊天、记忆、主动搭话、语音都还在服务器上跑。

## 三步

### 1. 起一个「专用 Edge」

双击 `start-edge.bat`。它会用**独立配置目录**（`D:\ccPrograms\EdgeDouyin`）开一个 Edge：

- 跟你日常用的 Edge **完全隔离**，不碰书签、密码、登录态
- 带 `--remote-debugging-port=9222`，采集脚本靠它接管
- **第一次要扫码登录抖音**，之后长期记住

> 已经开着的日常 Edge 接管不了——浏览器只允许**启动时**开调试口。这不是我偷懒，是它的安全设计。

### 2. 装依赖、填配置

```bash
cd tools/douyin
npm init -y
npm i playwright-core
copy config.example.json config.json
```

`config.json` 填两项：

| 字段 | 从哪来 |
|---|---|
| `server` | 你的服务器地址，如 `http://1.2.3.4:18080` |
| `token` | 面板 → 功能 → 刷抖音 → 「采集端令牌」右边点复制 |

### 3. 跑

```bash
node collect.mjs          # 跑一轮就退出
node collect.mjs --loop   # 常驻，按 checkIntervalMin 轮询面板开关
```

## 它会做什么

1. 拉面板配置。**「允许她刷抖音」是关的就直接退出**，一点不动
2. 不在允许时段、或者今天的点赞/收藏/分享额度用完了 → 跳过
3. 打开抖音推荐页，往下滚，每屏读一次：文案、作者、点赞数、时长
4. **硬筛**（纯代码，不花 token）：无文案 / 赞太少 / 太短 / 命中屏蔽词 → 跳过
5. 看到值得的：点赞、收藏、（可选）分享给你
6. 右下角挂个角标显示「她正在看：xxx」，这样你屏幕上能看到她在干嘛
7. 一轮结束把结果交回服务器，服务器注入给她，她就能在 QQ 里跟你聊

## 几个刻意的设计

**额度由服务器说了算。** 采集端不自己加量，`likeLeft` 归零就停。

**点不到就跳过，绝不硬按。** 抖音的 DOM 三天两头变，选择器全挂了也只是这轮没采到东西，
不会乱点、不会把赞点到别的地方。

**滚动和点击都有随机间隔**（2.5–6 秒），不是匀速机器。

**分享只发不读。** 走抖音自己的分享面板，只把视频发给你，不看你的消息、不自动回复。

**声音默认关掉**（`mute: true`）。不然你电脑会突然开始放抖音。

## 出问题了看这里

| 现象 | 原因 |
|---|---|
| `connectOverCDP ECONNREFUSED` | Edge 没带调试口。必须用 `start-edge.bat` 起 |
| 拉配置 401 | token 填错，或者面板里点过「重置」 |
| 采到 0 条 | 抖音改版了，选择器失效。看日志里的「跳过」原因 |
| 一直跳过（无文案） | 登录态掉了，页面显示的是登录引导页。回去扫码 |
| 分享一直失败 | 搜不到那个号。确认填的是**抖音号**不是昵称 |

## 风险

- 这是**自动化操作你的抖音账号**，违反平台用户协议，可能触发风控、限流、封号
- 所以额度默认很低（点赞 15、收藏 10、分享 3），**别往上调**
- 用**专门的号**，别拿主号试

作者（也就是给你搭这套的人）不对账号后果负责——这句话不是甩锅，是这类工具的真实边界。
